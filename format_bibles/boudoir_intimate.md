# Format Bible: Boudoir / Intimate

Source: adapted from an external smartphone-aesthetic prompt library
(camera/scene mechanics rewritten in this project's own schema and voice —
no text copied verbatim; NSFW-permission and output-length rules from the
source were dropped, since `constraints.md` and `model_specs/*.md` already
own those decisions in this pipeline).

A posed, editorial-adjacent format — the opposite instinct from every
candid/unposed format in this folder. She is aware of and composing for
the camera throughout. Whether this format is used at SFW or NSFW
explicitness for a given character is entirely a `constraints.md` decision
per `characters/CONTENT_HARD_LIMITS.md` — this file only describes the
camera/lighting/body mechanics, not permission to use them.

```
Camera:
- Shallow depth of field, wide-open aperture look — soft dreamy bokeh with
  sharp focus held on the eyes
- Medium-format or fast-prime-lens character (creamy rendering, gentle
  falloff) rather than a phone-selfie look — this is the one format in the
  folder styled as "photographed," not "self-shot"

Body:
- Composed, deliberate poses — reclined, half-turned, weight settled into
  soft furnishings (bed, chaise, floor cushions)
- Slow, minimal movement between poses if used for video; each pose held
  rather than transitioning quickly

Eyes:
- Half-lidded, soft, direct-to-lens gaze is the signature look — tender
  and present rather than performative or seductive-aggressive

Lighting:
- Soft warm window light from one side (upper-left is a reliable default),
  golden-hour light through sheer curtains, or candlelight as a warm
  practical fill — always warm, always soft, never harsh or clinical
- Gentle key light with no hard shadow edges

Setting:
- Bedroom-adjacent: soft furnishings, warm-toned linens, low clutter —
  reads as private and unhurried, not a staged studio set

Avoid:
- Harsh/clinical lighting or a "studio shoot" backdrop — breaks the
  intimate, private-moment read this format depends on
- Rushed pacing — this format's whole mood is unhurried; fast cuts or
  quick movement undercut it
```

## Best Suited For
A dedicated "intimate portrait" beat — distinct in mood and posing from
`mirror_selfie.md` (candid, self-aware-but-casual) and
`pov_first_person.md` (immersive, faceless). Use only for a character
whose `constraints.md` explicitly supports this register; check that file
before reaching for this format.
