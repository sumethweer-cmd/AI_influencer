# Format Bible: Mirror Selfie

```
Camera:
- Handheld phone, held at chest/hip height into a mirror
- Slight tilt, never perfectly level

Body:
- Weight on one leg, natural asymmetry
- Phone/arm visible in frame (holding the phone is part of the shot)

Eyes:
- Looking at own reflection/phone screen, not directly out at "camera-camera"

Movement:
- Minor phone-hand adjustment
- Slight hip/shoulder shift between shots in a set

Lighting:
- Whatever's actually in the room (bathroom/bedroom light), not styled

Avoid:
- Perfectly centered, dead-on symmetrical mirror shot (reads as studio, not candid)
- Missing phone/arm in frame
```

## Common Failure Patterns
- Output looks like a professional portrait instead of a phone selfie — check
  `photography.camera_style` explicitly forbids "editorial/professional/studio" language.

## Best Suited For
OOTD, gym mirror, "day in the life" content — pairs with `ugc.md`, `flirty.md`.
