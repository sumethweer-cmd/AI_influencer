# Content DNA: UGC (User-Generated-Content style)

## Structure
```
Attention Hook
Relatable Situation
Problem / Context
Product Introduction
Personal Experience
Product Attributes
Soft CTA
```

## When content-director should pick this
The piece is meant to read as an authentic, unscripted-feeling recommendation
or moment — the "product" (if any) is secondary to the relatable framing.

## Notes for character_take
Keep dialogue casual and specific (real details, not generic praise). If no
actual product is involved, this DNA still works for "relatable moment" content
— just drop the Product Introduction/Attributes beats.
