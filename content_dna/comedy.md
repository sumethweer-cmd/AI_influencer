# Content DNA: Comedy

## Structure
```
Hook
Setup
Expectation
Misdirection
Twist
Punchline
Reaction
```

## When content-director should pick this
The core_mechanic is built around a joke landing — the piece exists to make
the audience laugh, not primarily to inform, sell, or build parasocial closeness.

## Notes for character_take
The Twist/Punchline lines are where the character's `humor_style.md` matters
most — the mechanic (misdirection, double meaning, etc.) should come from that
file, not be invented fresh each time.
