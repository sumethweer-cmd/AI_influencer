# Content DNA: Affiliate

## Structure
```
Hook
Context (why this is relevant to her audience right now)
The Pitch
Proof / Personal Tie-in
Clear CTA (link/code)
```

## When content-director should pick this
Explicitly commercial — the CTA is not optional here (unlike `flirty.md`/`ugc.md`
where it's conditional on business_goal). Should still be filtered through
`business_goal.md`'s `cta_style` so it doesn't read as generic ad copy.

## Notes for character_take
This is the one category where a hard CTA is expected by default — but the
character's actual voice (speaking_style/humor_style) should still carry the
pitch, not a templated ad read.
