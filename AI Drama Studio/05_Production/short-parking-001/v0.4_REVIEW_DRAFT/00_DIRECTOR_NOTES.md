## 1. การอ่านบทแบบ Director

**แกนเรื่อง**: "แป๊บเดียว" ของคนหนึ่ง = เวลาที่ถูกขโมยจากอีกคน และเมื่อคนที่ผิดกลัวเสียหน้า เขาใช้ *กลุ่มแชตหมู่บ้าน* เป็นอาวุธ ฝนไม่ได้ชนะด้วยเสียงดัง แต่ชนะด้วย **หลักฐาน + ความนิ่ง + การไม่ยอมให้แค่ "ลบ" แล้วจบ**

**สิ่งที่คนดูต้อง "ได้เรียน" โดยไม่มีใครพูดสอน** (ผ่านภาพ ไม่ใช่บท):
1. ความสะดวกของเราเป็นต้นทุนของคนอื่น → ภาพ: กาแฟที่ยังมีไอ vs นาฬิกา/จอโทรศัพท์ของฝน
2. การประจานในกลุ่มคือความรุนแรงรูปแบบหนึ่ง และ "ลบ" ไม่ได้ย้อนผลที่คนเห็นไปแล้ว
3. การขอโทษที่มีค่าคือการขอโทษ **ที่มีการกระทำรองรับ** → ภาพ: ที่จอดว่าง, ตอนจบหน้าประตูฝนว่าง

**Emotional map (ตามที่เสนอใน handoff) → วิธีทำให้ถึงคนดู**
| ช่วง | อารมณ์คนดู | เครื่องมือกำกับ |
|---|---|---|
| S01 ต้น–กลาง | อึดอัดแทนฝน | push-in ช้ามากที่หน้าฝน, ซี่ประตูรั้วเป็น foreground คั่นระหว่างฝนกับอ้อย, เสียงถ้วยกาแฟ/จิบเป็นจังหวะกวนใจ, ฝนเหลือบดูเวลาซ้ำๆ |
| S01 ท้าย | โกรธที่ถูกเมิน | "ก็ขยับสิคะ!" สั้น คม ไม่ยาว; ถ้วยหยุดกลางอากาศ = จุดหยุดเวลา |
| S02 ต้น | เจ็บเมื่อถูกถ่าย | shot จาก "เลนส์โทรศัพท์อ้อย" มองฝน (phone เป็นอาวุธ) ฝนผงะ |
| S02 กลาง | ลุ้นเมื่อฝนโต้ด้วยหลักฐาน | ฝนนิ่งขึ้นเมื่ออ้อยหยุดถ่าย; ตัดไปจอแชตเก่า (อ่านชัด) แล้วค้างที่หน้าอ้อยตอนรอยยิ้มหาย |
| S02 ท้าย | ยังไม่โล่ง (ต้องมีแรงดึง) | ฝนไม่ถอยหลังรถถูกขยับ — "พี่แก้ให้หนูด้วย" ไม่หลบตา |
| S02 จบ | อ้อยเริ่มเปลี่ยนแบบเงียบ | ฉากไร้บทพูด close-up จอ+หน้า: พิมพ์แก้ตัว → เห็น "จ้า" ของตัวเอง → ลบทีละคำ (หัวใจของตอน) |
| S03 | โล่งแบบมีน้ำหนัก ไม่หวาน | locked-off, golden hour, สมมาตรขึ้น, จังหวะช้าลง, ไม่กอด, จบด้วยหน้าประตูว่าง |

**Visual language**
- **สี**: ฝน = teal เย็น, อ้อย = terracotta อุ่น (คู่ complementary ปะทะกันเอง), สามี = navy กลางๆ → คนดูเลือกข้างด้วยสีและพฤติกรรม ไม่ใช้รูปร่างหน้าตาตัดสิน
- **ซี่รั้ว**: ฝนอยู่นอกรั้ว (ถนน) อ้อยอยู่ใน "พื้นที่ของตัวเอง" แต่คนที่ติดอยู่จริงคือฝน — ใช้ซี่รั้วเป็น foreground ใน S01 แล้ว *ค่อยเปิดโล่ง* ใน S03 (ไม่มีรั้วคั่นในช็อตสนทนา)
- **เวลา**: motif "ฝนดูเวลา" (นาฬิกา/จอโทรศัพท์) ต้องมี 3–4 ครั้งใน S01–S02; S03 ไม่มีเลย
- **กล้อง**: S01 นิ่ง + push-in ช้า / S02 handheld นิดๆ + POV เลนส์โทรศัพท์ / S03 locked-off
- **เสียง**: ถ้วยกระทบจาน, แจ้งเตือนไลน์/กลุ่ม (ทำเป็น sound motif: ครั้งแรกทำให้อ้อยลุก ครั้งสุดท้ายไม่มี), S03 เสียงนกเย็น + รถ; เพลงประกอบ: ไม่ใส่จน S03 (ใส่ใน edit ตามชอบ)

## 2. ข้อสังเกตต่อบท (ส่ง Creative/ผู้ใช้ตัดสิน — ผมไม่แก้บทเอง)
บทดีแล้วในระดับ pilot; จุดที่ director เห็นว่าควรตัดสินก่อนถ่าย/เจน:
1. **คลิปมีเสียง "ดูนะคะ…"** — อ้อยพูดต่อกล้องใน S02 ดีมาก เป็นจุดที่ทำให้คนดู "เกลียดพฤติกรรม" ไม่ใช่ตัวคน เก็บไว้
2. **รถอ้อยหลัง S02**: บทบอก "เสียงรถอ้อยเคลื่อนออกจากหน้าประตู" แต่ S03 รถ "จอดในบ้านแล้ว" และสามีอยู่บ้านช่วยย้ายโต๊ะ → **สมมติฐาน (PROPOSED)**: สามีขับรถไปทำงาน (เขาสะพายกระเป๋าทำงานอยู่แล้ว) แล้วกลับมาจอดในบ้านตอนเย็น; กุญแจที่ S03 อยู่บนโต๊ะ = สามีวางไว้หลังจอด ไม่ต้องมีช็อตส่งกุญแจเพิ่ม *(ผู้ใช้โปรดยืนยัน)*
3. **ฝนอ่านข้อความแก้ไขตอนเย็น**: เป็นช็อตจอ (UI-06) — ต้องทำตัวอักษรใน edit ไม่พึ่งโมเดล
4. **ข้อความสอน** (ที่ผู้ใช้อยากให้ "สอนไปในตัว"): บทเลี่ยงประโยคสอนเอง ตรงตามกฎ studio ถ้าจะเพิ่ม end-card/overlay (เช่นประโยคสั้นหลังคำว่า "จบ") ให้ถือเป็น **OPEN QUESTION** ผู้ใช้ตัดสินและให้ Creative เขียน ผมไม่ใส่ในบทและไม่ใส่ใน prompt
5. **ความยาว**: รวมเวลา clip ตามแผนนี้ ≈ **4:25 (raw)** ตัดหัว/ท้ายคลิปแล้วน่าจะ ≈ 3:40–4:00 เกินเป้า 3–4 นาทีเล็กน้อย — ถ้าต้องลด ตัดได้ตามนี้โดยไม่เสียความหมาย: S01-06+S01-11 (รีแอคชั่นสั้นๆของอ้อย) รวมเข้าช็อตข้างเคียง, S02-17, S02-20/22
6. **ภาษาไทยในเสียง MiniMax H3**: ยังไม่ทราบว่าพูดไทย+ลิปซิงก์ได้ดีแค่ไหน → ดูหัวข้อ 5

## 3. Visual & Geography Lock (PROPOSED — ผู้ใช้ยืนยันก่อนเจน frame)
เอกสาร handoff บอกชัดว่ายังไม่กำหนด ซ้าย/ขวา สีรั้ว ประตู รถ จึง **เสนอ** ชุดเดียวตายตัว:
- **Screen direction (เส้น 180°)**: มองจากถนนเข้าหาบ้าน — **บ้านฝนอยู่ซ้ายเฟรม, บ้านอ้อยขวาเฟรม** ฝนอยู่ *ซ้ายเฟรม* ในทุกช็อตสนทนา อ้อยอยู่ *ขวาเฟรม* ห้ามข้ามเส้น
- **รถอ้อย**: เก๋งกะทัดรัดสีขาวมุก ไม่มีโลโก้ ทะเบียนเป็นกลุ่มตัวเลขสมมติ *อ่านไม่ชัด* (ใน S02 อ้อยพูดถึง "ทะเบียน" — ให้เห็นแผ่นทะเบียนได้แต่ใช้เลขสมมติ)
- **รถฝน**: แฮชแบ็กเทาเข้ม จอดในรั้วบ้านฝน หันหน้าออกหาประตู
- **รั้วบ้านอ้อย**: รั้วเหล็กดัดซี่แนวตั้งสีเขียวเข้ม/ดำ สูงระดับอก มีช่องที่ยื่นมือเข้าได้ ติดกริ่งที่เสา; โต๊ะกลมเล็ก + เก้าอี้ 2 ตัวอยู่ในโรงจอดรถ ห่างรั้วประมาณ 1–1.5 ม. (ฝนยื่นมือ/มองเห็นกุญแจบนโต๊ะได้)
- **บ้านฝน**: รั้ว+ประตูเลื่อนโทนเทา/ขาว ธรรมดา ติดรั้วบ้านอ้อย
- **แสง**: เช้า แดดอ่อนมุมต่ำจากขวาเฟรม; เย็น golden hour อุ่นจากซ้ายเฟรม
- **ทิศการเดิน**: ฝนเดินจากซ้าย→ขวา (ไปหาอ้อย), ออกขับไปทางซ้าย; รถอ้อยถอย/เคลื่อนออกไปทางขวา

**ความไม่ตรงของ reference ที่พบจริง (ตามกฎ: บันทึกความคลาดเคลื่อน)**

- ฝน: ด้านยาวของบ๊อบอยู่ **ขวาของตัวละคร** (ซ้ายเฟรมตอนหน้าตรง) ด้านซ้ายตัวละครเปิดหู มีไฝใต้ตาซ้าย; ภาพหน้าตรงเห็นไฝไม่ชัด ให้ตรวจ frame ทุกครั้ง
- สามี: ปอยขาวอยู่ด้านขวาของตัวละคร (ซ้ายเฟรมตอนหน้าตรง) ตรงกับภาพ
- ภาพ v1 สีหน้าเรียบ (identity ไม่ใช่ expression sheet) → ต้องสั่งสีหน้าในแต่ละ frame/prompt

## 5. Settings & ความสามารถ MiniMax H3 (ตรวจจากไฟล์จริงแล้ว)
อ่านจาก `MiniMax H3/MiniMax - I2V - Custom Prompt.json` (workflow ของ HearmemanAI):
- node `MiniMaxH3ImageToVideo`: รับ `first_frame` + `last_frame` (**ไม่บังคับ**) + `prompt` + width/height + length
- โมเดล `minimax_h3_fl2va` มี audio VAE → prompt ใส่ **เสียง/บทพูดในเครื่องหมายคำพูด** ได้ (ตามตัวอย่างใน workflow: บรรยายเสียงแล้วใส่ประโยคในเครื่องหมายคำพูด)
- ResolutionSelector ตั้ง 9:16, output 24 fps, ค่า duration default 5 วินาที
- **ยังไม่ยืนยัน (ต้องทดสอบจริง)**: พูดภาษาไทยออกเสียงได้ไหม/ลิปซิงก์, ความยาวสูงสุดต่อคลิป (shot ที่ผมกำหนด 3–6 วินาที), ความแม่นของ identity จาก first frame
- **แผนทดสอบ 3 ช็อตก่อนเจนทั้งเรื่อง**: S01-02 (บทพูด+ท่าทาง), S02-02 (ฝนผงะ/สีหน้า), S02-16 (มือส่งกุญแจ — เสี่ยงมือ)
- **fallback เสียงไทย**: ถ้าเสียงไทยไม่ดี → เจนภาพ+ปากขยับ แล้วพากย์ด้วยเสียงจริง/TTS ใน edit (prompt ทุกอันเขียนให้ใช้ได้ทั้งสองทาง)
- ทุกคลิป: "หนึ่ง action หลักต่อ shot" ตาม PRODUCTION_HANDOFF; ไม่มีเหตุการณ์/บทพูดนอกบท
