## 1. อ่านเรื่องนี้อย่างไร
ละครสั้นแนวตั้งภาษาไทย แนวคุณธรรม/จิกกัดสังคม จบในตอน ความยาวเป้าหมาย 3–4 นาที ยังไม่ได้จับเวลาอ่านหรือแสดงจริง
แกนเรื่อง: คนที่พูดว่า “แค่แป๊บเดียว” กำลังผลักเวลาที่เสียและผลกระทบให้คนอื่นรับแทน
คำถามที่คนดูรอ: ฝนจะออกจากบ้านได้อย่างไร และจะแก้ข้อกล่าวหาที่อ้อยโพสต์ให้คนในหมู่บ้านเข้าใจผิดได้หรือไม่?
อารมณ์ที่ต้องได้: อึดอัดแทนฝน → โกรธที่ถูกเมินและโยนความผิด → เจ็บเมื่อถูกถ่ายประจาน → ลุ้นเมื่อฝนโต้กลับด้วยหลักฐาน → โล่งเมื่อได้ทั้งทางออกบ้านและการแก้คำกล่าวหา
โทนสมจริง ภาษาคนคุยกัน มีแรงปะทะแต่ไม่ใช่การตะโกนตลอดเรื่อง ไม่ใช้ประโยคสอนคุณธรรมแทนเหตุการณ์

## 2. เรื่องย่อครบต้นจนจบ
ฝนต้องออกไปทำงาน แต่รถอ้อยซึ่งเป็นเพื่อนบ้านจอดขวางประตูบ้านเธออีกครั้ง ฝนขอให้ขยับอย่างสุภาพ อ้อยมีทั้งกุญแจและเวลาจะช่วย แต่ยังนั่งกินกาแฟและบอกให้รอ ฝนถูกหัวหน้าโทรตามและเรียกคุยเรื่องมาสาย เมื่อเสนอขยับรถให้อ้อยเองก็ถูกปฏิเสธ เธอจึงหลุดเสียงและส่งภาพรถขวางลงกลุ่มหมู่บ้าน

อ้อยกลัวเสียหน้า จึงถ่ายคลิปฝนโดยกล่าวหาว่ามาด่าถึงบ้าน ฝนท้าให้ถ่ายรถกับประตูบ้านเพื่อให้เห็นเหตุของการโต้เถียง แต่อ้อยส่งคลิปเข้ากลุ่ม ฝนจึงส่งภาพและแชตเก่าที่แสดงว่าขอให้ขยับมาหลายวันแล้ว สามีอ้อยออกมาเห็นสถานการณ์และช่วยขยับรถ แต่ฝนยังทวงให้อ้อยแก้คำกล่าวหาต่อคนกลุ่มเดิม เพราะลบคลิปอย่างเดียวไม่ทำให้คนที่ดูแล้วรู้ความจริง

หลังฝนออกไป อ้อยกำลังจะพิมพ์แก้ตัว แต่เห็นข้อความเก่าที่ฝนเคยขอไม่ให้จอดขวางและคำตอบรับของตัวเอง จึงลบข้อความแก้ตัว ช่วงเย็นอ้อยกับสามีจัดที่จอดรถในบ้าน อ้อยชี้แจงและขอโทษฝนในกลุ่ม แล้วขอโทษต่อหน้า ฝนไม่ได้กลายเป็นเพื่อนสนิททันที เธอย้ำว่าพรุ่งนี้ต้องออกเจ็ดโมง เรื่องจบที่หน้าประตูบ้านฝนว่าง และพฤติกรรมอ้อยเปลี่ยนจริง

## 3. ใครเป็นใคร
อายุและรายละเอียดรูปลักษณ์ต่อไปนี้เป็นข้อเสนอจากภาพ v1 ไม่ใช่ข้อมูลที่เพิ่มย้อนหลังให้บทพูด

### FON — ฝน
- บทบาท: ตัวละครหลัก คนทำงานที่ได้รับผลกระทบจากการจอดขวางซ้ำ
- ความสัมพันธ์: เพื่อนบ้านอ้อยและสามีอ้อย ไม่ใช่ญาติ คำว่า “พี่” เป็นคำเรียกคนอายุมากกว่า
- เป้าหมาย: ออกไปทำงานให้ทัน จากนั้นต้องการให้คนในกลุ่มรู้ว่าเธอมาขอทางออก ไม่ได้มาด่าหาเรื่อง
- เดิมพัน: ไปสายซ้ำ ถูกหัวหน้าเรียกคุย และเสียชื่อในกลุ่มหมู่บ้าน บทนี้ไม่มีการถูกไล่ออกหรือถูกยกเลิกทดลองงาน
- บุคลิก: เกรงใจและพยายามพูดดี แต่มีขอบเขต เมื่อถูกกดดันจะโต้กลับและใช้หลักฐาน ไม่รอให้คนอื่นแก้ทุกอย่างให้
- การแสดง: รีบแต่ยังคุมเสียง → ลดเสียงตอนรับสายหัวหน้า → ความอดทนหมดตอนอ้อยไม่ให้กุญแจ → ผงะเมื่อถูกถ่าย → มองตรงและตั้งคำถาม → ยืนรอให้แก้ข้อกล่าวหา → เหนื่อยแต่ผ่อนลงเมื่อกลับบ้าน
- เสียงพูด: ใช้ “หนู/พี่” ประโยคสั้นตามสิ่งที่ต้องการตอนนั้น ไม่พูดสรุปหลักศีลธรรมยาว ๆ
- ลุคประมาณ 28–32 ปี: บ๊อบสั้นไม่สมมาตร ด้านขวาของตัวละครยาวกว่า ด้านซ้ายเปิดหู มีไฝเล็กใต้ตาซ้าย เสื้อเขียวหม่นอมฟ้า กางเกงเทาเข้ม กระเป๋ามัสตาร์ด
- ภาพหลัก: References/Characters/fon-reference-v1.png

### AOY — อ้อย
- บทบาท: เพื่อนบ้านผู้สร้างปัญหาและคู่ขัดแย้งหลัก
- ความสัมพันธ์: ภรรยาของ AOY-HUSBAND อยู่บ้านติดกับฝน
- เป้าหมายต้นเรื่อง: รักษาความสะดวกของตัวเอง ไม่อยากถูกเร่ง เป้าหมายหลังภาพเข้ากลุ่มคือปกป้องหน้าตา
- ต้นเหตุ: ใช้พื้นที่จอดรถในบ้านวางโต๊ะ/กระถาง แล้วจอดรถขวางทางออกฝนแทน
- บุคลิก: ชินกับการให้คนอื่นรอ ลดทอนความเสียหายด้วยคำว่า “แป๊บเดียว” เมื่อถูกโต้กลับจะจับเรื่องน้ำเสียงมากกว่าปัญหาที่ตัวเองก่อ
- การแสดง: จิบกาแฟทั้งที่เห็นคนรีบ → ตื่นตัวทันทีเมื่อรูปเข้ากลุ่ม → ใช้โทรศัพท์กดดัน → รอยยิ้มหายเมื่อเห็นแชตเก่า → พยายามต่อรองให้ลบ → ชะงักเมื่ออ่านคำรับปากตัวเอง → ขอโทษอย่างไม่คล่องปาก
- เสียงพูด: พูดกับฝนห้วนและตัดบท เปลี่ยนเป็น “ดูนะคะ” เมื่อบันทึกคลิปเพื่อให้คนอื่นเข้าข้าง
- ลุคประมาณ 43–48 ปี: หน้าม้าสั้นตรง มวยสูงกว้าง/ทรงพัด ปิ่นแดงเข้ม เสื้อสีอิฐขอบครีม กางเกงน้ำตาล ต่างหูห่วงเล็ก
- ภาพหลัก: References/Characters/aoy-reference-v1.png
- การทำให้คนดูไม่พอใจต้องมาจากพฤติกรรม ไม่ใช้รูปร่างหรือหน้าตาเป็นสัญลักษณ์ว่าคนนี้เลว

### AOY-HUSBAND — สามีอ้อย
- ยังไม่มีชื่อส่วนตัวในบท ใช้ ID นี้และชื่อเรียก “สามีอ้อย” ไม่ตั้งชื่อเพิ่มเอง
- บทบาท: คนในบ้านอ้อยที่เห็นปัญหา ช่วยขยับรถและจัดพื้นที่จอด ไม่ใช่ผู้มีอำนาจที่มาเฉลยหรือสอนทุกคน
- ความสัมพันธ์: สามีอ้อยและเพื่อนบ้านฝน ไม่มีความสัมพันธ์เชิงรักกับฝน
- รู้เรื่องจาก: เห็นข้อความในกลุ่มและรถที่ขวางอยู่ ไม่ต้องมีข้อมูลลับหรือเห็นเหตุการณ์ตั้งแต่ต้น
- การแสดง: ประเมินเหตุการณ์จากรถและกุญแจ → ขอเอากุญแจไปขยับ → ช่วยย้ายของช่วงเย็น
- เสียงพูด: สั้น ตรง มุ่งแก้ปัญหา ไม่แย่งช่วงเผชิญหน้าของฝน
- ลุคประมาณ 46–52 ปี: แฟลตท็อปสั้น ปอยขาวเด่นด้านขวาของตัวละคร แว่นเหลี่ยมหนา เสื้อทำงานน้ำเงินหม่น กางเกงกรม กระเป๋าดำ
- ภาพหลัก: References/Characters/aoy-husband-reference-v1.png

## 4. ลำดับฉากและหน้าที่ทางอารมณ์
| Scene | เวลา | เหตุการณ์สำคัญ | สภาพก่อน → หลัง |
|---|---|---|---|
| S01 | เช้า | ขอขยับรถ รับสายหัวหน้า เสนอขยับเอง ถูกปฏิเสธ ส่งรูปเข้ากลุ่ม | ฝนยังเกรงใจ → เริ่มยืนยันสิทธิ; อ้อยเฉยเมย → กลัวเสียหน้า |
| S02 | เช้าต่อเนื่อง | ถ่ายกล่าวหา ฝนส่งหลักฐาน สามีขยับรถ ฝนทวงคำชี้แจง อ้อยอ่านแชตเก่า | ฝนถูกทำให้ดูผิด → เป็นผู้ตั้งเงื่อนไขให้แก้ความจริง; อ้อยแก้ตัว → เริ่มยอมรับ |
| S03 | เย็นวันเดียวกัน | จัดที่จอดในบ้าน ชี้แจงในกลุ่ม ขอโทษต่อหน้า | คำยอมรับผิดมีการกระทำรองรับ; ฝนได้ทางออกบ้านและชื่อเสียงคืน |
ภาพรถ/แชตเก่าแสดงเหตุการณ์หลายวันก่อน ไม่ใช่ฉากย้อนหลังที่ต้องเพิ่มขึ้นเอง

## 5. สถานที่และสิ่งของที่ต้องต่อเนื่อง
สถานที่หลักคือหน้าบ้านสองหลังที่ติดกันในหมู่บ้านร่วมสมัย มีรั้วและประตูรถแยกกัน บ้านฝนมีรถอยู่ด้านใน บ้านอ้อยมีมุมโต๊ะกาแฟและของกินพื้นที่จอดรถ
ยังไม่ได้กำหนดซ้าย/ขวาของสองบ้าน สีรั้ว แบบประตู ยี่ห้อ/สีรถ หรือเลขทะเบียน ต้องออกแบบและบันทึกชุดเดียวก่อนแตกภาพหลายมุม ไม่เปลี่ยนไปมาตาม prompt
ข้อจำเป็นทางกายภาพ: รถอ้อยขวางทางออกรถฝนจริง; ฝนเดินออกมาคุยที่รั้วอ้อยได้; มีช่องประตูที่ฝนยื่นมือได้; โต๊ะและอ้อยมองเห็นกันจากตำแหน่งฝน
มีรถจำเป็นสองคัน: รถฝนและรถอ้อย บทไม่ต้องแสดงรถส่วนตัวสามีเพิ่ม

| สิ่งของ | ความต่อเนื่อง |
|---|---|
| กุญแจรถอ้อย | คล้องนิ้วตอนออกมา → วางข้างแก้ว → อ้อยรวบคืนเมื่อฝนขอ → ส่งให้สามีใน S02 → ตอนจบอยู่โต๊ะก่อนอ้อยนำเข้าเก็บ |
| รถอ้อย | ขวางบ้านฝน S01–ก่อนสามีขยับใน S02 → พ้นทางให้ฝนออก → จอดในบ้านอ้อย S03 |
| โทรศัพท์ฝน | ถ่ายภาพเช้าวันนี้ → รับสาย → ส่งภาพเข้ากลุ่ม → เห็นคลิป → ส่งหลักฐานเก่า → อ่านคำชี้แจงตอนเย็น |
| โทรศัพท์อ้อย | รับแจ้งเตือน → เริ่มถ่ายใน S02 → หยุดและส่งคลิป → อ่านหลักฐาน → พิมพ์แล้วลบคำแก้ตัว → มีคำชี้แจงในกลุ่มตอนเย็น |
| กาแฟ/โต๊ะ/กระถาง | ช่วงเช้าแสดงความชะล่าใจและพื้นที่จอดที่ใช้ผิดหน้าที่; ตอนเย็นจัดหลบให้รถเข้าบ้านได้ |
| เสื้อผ้า/กระเป๋า | S01–S02 ต่อเนื่องทันที ชุดและของต้องเหมือนกัน; S03 วันเดียวกันยังใช้ reference ชุดเดิมเป็นค่าเริ่มต้น |

การคืนกุญแจจากสามีสู่โต๊ะไม่ได้มีฉากเฉพาะ ให้ staging รองรับได้โดยไม่สร้าง subplot หรือตัดต่อให้กุญแจหาย/เพิ่มกลางช็อต
ตรวจมือที่ถือแก้ว/กุญแจ/โทรศัพท์ให้ทำได้จริง อ้อยต้องวางแก้วก่อนใช้โทรศัพท์ ไม่เพิ่มมือหรือให้ของเปลี่ยนเจ้าของโดยไม่มีการส่ง

## 6. หลักฐานและข้อความบนมือถือ
- ภาพเช้าวันนี้ต้องเห็นรถอ้อยสัมพันธ์กับประตูบ้านฝน ไม่ใช่เพียงภาพรถจอดริมถนน
- แชตเก่ามีภาพต่างวัน ข้อความขอขยับ และคำตอบ “รอแป๊บ” ใช้วันเวลาเรียงก่อนเช้าวันปัจจุบัน
- อ้อยเริ่มถ่ายใน S02 คลิปไม่สามารถมีคำพูดจาก S01 ก่อนเริ่มถ่าย ไม่อ้างว่าฝนบันทึกวิดีโอไว้ เพราะบทกำหนดเพียงภาพนิ่งและข้อความ
- หัวข้อคลิปคืออ้อยกล่าวหาว่าฝนมาด่า อย่าเพิ่มการตัดต่อปลอมหลักฐานหรือ live stream ที่ไม่มีในบท
- ข้อความที่ทำให้อ้อยหยุดแก้ตัว: “วันนี้หนูไปสายอีกแล้วค่ะ พรุ่งนี้อย่าจอดขวางนะคะ” และคำตอบของอ้อย “จ้า”
- คำชี้แจงตอนเย็นต้องส่งในกลุ่มเดิมที่ได้รับคลิป จึงตอบปัญหาชื่อเสียงได้
- ใช้ข้อความตรงจากบท 0.4 สำหรับภาพข้อความ ห้ามสร้างชื่อ/เบอร์/แชตบุคคลจริงขึ้นมา
- หากภาพ GenAI ทำข้อความอ่านไม่ได้ ให้วางแผนทำข้อความในขั้น compositing/editing แยก ไม่พึ่งตัวอักษรที่โมเดลสร้างผิด

## 7. สิ่งที่ห้ามคลาดเคลื่อนตอนแปลง Production
- ฝนไม่จอดขวางกลับ ไม่วางกับดัก ไม่ถูกไล่ออก และไม่ได้ไปทดลองงานในฉบับ 0.4
- ความสำเร็จของฝนมีสองส่วน: ได้ออกจากบ้านและได้แก้คำกล่าวหา อย่าจบแค่สามีขยับรถ
- สามีไม่ใช่คนยื่นหลักฐาน ฝนส่งเองและเป็นคนทวงให้อ้อยชี้แจง
- อ้อยไม่ได้สำนึกทันทีหลังโดนสวน การอ่านคำรับปากตัวเองเป็นจังหวะเชื่อมไปสู่การแก้ไข
- ตอนจบฝนรับรู้คำขอโทษแต่ยังย้ำขอบเขต ไม่เพิ่มการกอดคืนดีหรือกลายเป็นเพื่อนสนิท
- รักษาบทพูดและความหมาย ไม่เปลี่ยนเป็นภาษาทางการ เพิ่มคำคม หรือเติมบทสอนคนดู
- ภาพ v1 เป็น identity/wardrobe reference สีหน้ายังไม่ครอบคลุมทุกอารมณ์ ตอนทำฉากต้องรักษาหน้าตาเดิมแล้วเปลี่ยน expression ตามบท
- ล็อกด้านของทรงผม ไฝ และปอยขาวตามภาพจริง รายละเอียดการสร้าง prompt เดิมบางด้านคลาดจากภาพ ให้ภาพกับ CHARACTER_REFERENCES.md เป็นหลัก
- อ่านภาพแผ่นรวมเป็น reference ของคนเดียวหลายมุม อย่าสร้างคนหลายคนในฉากเพราะเห็นหลายรูปในแผ่นเดียว
