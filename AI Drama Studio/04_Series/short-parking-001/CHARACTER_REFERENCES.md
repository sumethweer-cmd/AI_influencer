## FON — ฝน
ภาพ: References/Characters/fon-reference-v1.png
วัยที่ออกแบบประมาณ 28–32 ปี ผิวไทยโทนอุ่น เสื้อทำงานสีเขียวหม่นอมฟ้า กางเกงสีเทาเข้ม กระเป๋าผ้าสีเหลืองมัสตาร์ด
จุดจำ: บ๊อบสั้นไม่สมมาตร ฝั่งที่ยาวอยู่ซ้ายมือผู้ชมในภาพหน้าตรง (ด้านขวาของตัวละคร) อีกฝั่งเปิดหู ผมด้านหน้าปัดเฉียง มีไฝเล็กใต้ตาฝั่งซ้ายของตัวละคร
อารมณ์หลักในบท: พยายามเกรงใจ → ถูกเมิน → หมดความอดทน → ยืนยันทวงความเป็นธรรม
รักษาทรงผมและด้านของไฝตามภาพจริง ไม่กลับภาพเมื่อใช้เป็น reference

## AOY — อ้อย
ภาพ: References/Characters/aoy-reference-v1.png
วัยที่ออกแบบประมาณ 43–48 ปี เสื้ออยู่บ้านสีอิฐขอบครีม กางเกงน้ำตาล ต่างหูห่วงเล็ก
จุดจำ: หน้าม้าสั้นตรง มวยสูงทรงพัด/ม้วนกว้าง ปิ่นสีแดงเข้ม
อารมณ์หลัก: ชะล่าใจ → ปกป้องหน้าตัวเอง → ถูกหลักฐานย้อน → ยอมแก้คำกล่าวหา
หน้าตาและรูปร่างไม่ใช่เครื่องหมายความเลว การแสดงและการกระทำเป็นตัวสื่อบทบาท

## AOY-HUSBAND — สามีอ้อย
ภาพ: References/Characters/aoy-husband-reference-v1.png
วัยที่ออกแบบประมาณ 46–52 ปี เสื้อทำงานสีน้ำเงินหม่น กางเกงกรม กระเป๋าทำงานดำ
จุดจำ: ผมแฟลตท็อปสั้น ปอยขาวเด่นบริเวณหน้าฝั่งซ้ายมือผู้ชมในภาพหน้าตรง (ด้านขวาของตัวละคร) แว่นเหลี่ยมกรอบหนาสีกระ
อารมณ์หลัก: เหนื่อยกับปัญหา → เห็นข้อเท็จจริง → ลงมือช่วยจัดการ

## Usage and inspection
ทั้งสามภาพมีภาพเต็มตัว หน้าตรง สามส่วน และด้านข้าง ใช้เป็น identity/wardrobe reference
ตรวจภาพแล้ว: บุคลิกและรูปทรงผมแยกกันชัด ภาพแต่ละคนมีความสอดคล้องโดยรวม
สีหน้าในชุดแรกยังละเอียดอ่อน เหมาะเป็น identity reference มากกว่า expression sheet ครบทุกอารมณ์
คำบรรยายด้านซ้าย/ขวาใน prompt บางจุดไม่ตรงผลภาพ ให้ใช้ภาพและข้อสังเกตข้างบนเป็นฐานเมื่อพัฒนาต่อ
อายุและชุดเป็นข้อเสนอการออกแบบ ยังไม่ใช่ canon ที่ผู้ใช้อนุมัติ
ภาพเป็น reference แยกจาก shot prompts และ video production ซึ่งยังต้องใช้ approved script
