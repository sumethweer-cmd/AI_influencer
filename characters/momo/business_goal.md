## Funnel Structure (locked 2026-09-10)

Momo shares Anong's silent/no-dialogue format bibles at the top of the
funnel — same prompts, only `<Picture 1>` (character reference) swapped —
since both characters draw from the same reach/hook mechanics. What differs
between them is which funnel stage each pillar maps to, and that Momo skips
the trust-building stage entirely (see below).

```
FUNNEL 1 — Reach (broad, algorithm-friendly)
  Goal:      get seen, get known — no selling, no soft CTA
  Content:   comedy, silent/no-dialogue (reuses Anong's format bibles —
             candid_single_take, silent_reaction_beats, candid_activity_glimpse,
             silent narrative comedy like the ghost/cockroach piece — same
             prompts, swap <Picture 1> to Momo's reference), some
             double-entendre/สองแง่สองง่าม allowed per humor_style.md
  Platform:  IG-leaning (organic reach favors this format there)
  CTA:       none

FUNNEL 2 — Mid (existing-follower eye-hook)
  Goal:      let followers discover "this side of Momo" exists
  Content:   outfit/look-focused photo & video, sexy as the eye-hook itself
             — NOT informational/trust content (that's Anong's pillar, not
             Momo's — Momo's monetization doesn't need a credibility layer)
  CTA:       none

FUNNEL 3 — Convert (Fanvue)
  Goal:      convert warmed-up followers into Fanvue subscribers/chatters
  Content:   same visual register as funnel 2, but with an explicit CTA
             beat — "want to see more / support Momo → Fanvue"
  CTA:       explicit, direct — the only stage where a hard CTA belongs
```
